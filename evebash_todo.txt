EVEBASH - TODO (NEW FEATURES)
=============================
New things we want to build (features and improvements), for the website and/or phone app.
Share this file in chats and keep it in the repo so everyone knows what is planned.

Which file to use:
- Bugs (something is broken)              -> evebash_issue.txt
- Checks by hand on a real device         -> test_yourself.txt
- New features and improvements (planned) -> this file

HOW TO USE
- New todo: add it at the end of ACTIVE TODOS with the "Next todo number" below, then increase
  that number by 1. Never reuse a number. Pull staging first so two chats don't take the same number.
- Starting work: set Status to "In progress" and Owner to your name.
- After discussing it: set Discussed to Yes and write what was agreed in Decision.
- Shipped (merged to staging): set Status to "Done" and add "Done in: <commit> (YYYY-MM-DD)".
  If it needs a check on a device, add a test in test_yourself.txt and note its number in Done in.
- Dropped: set Status to "Dropped" and say why in Decision.
- Delete Done and Dropped entries once they are older than 14 days.
- Dates are YYYY-MM-DD.

Field values:
- Platform:     App | Website | Both | Analytics dashboard | Backend only
- Priority:     High | Medium | Low
- Phase:        1 (v1 launch) | 2 (after launch, incl. business features) | 3 (later / nice to have)
                | TBD (not decided yet, e.g. "TBD (1 or 2, decide after discussion)")
- Status:       Idea | Agreed | In progress | Done | Dropped
- Effort:       S (a few hours) | M (1-3 days) | L (a week or more)
- Suggested by: a name, or where it came from (a user, an audit, a competitor)
- Discussed:    Yes | No
- Decision:     what was agreed when discussed, or "-"
- Owner:        a name, or Unassigned
- Depends on:   another todo, an issue number, a decision, or "-"
