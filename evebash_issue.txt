EVEBASH ACTIVE ISSUES
=====================

How to use this file (people and Claude sessions alike):
- Read this file before starting work, and check whether your change fixes or touches any issue here.
- New issue: add it at the end of ACTIVE ISSUES with the "Next issue number" below, then increase that number by 1.
- Numbers are never reused. If #1 is fixed and removed, the next new issue still takes the next number.
- Starting work on an issue: set Status to "In progress" and Owner to your name.
- Fixed (merged to staging): move the whole entry to RECENTLY FIXED, set Status to "Fixed", and add
  "Fixed in: <commit> (YYYY-MM-DD)". Delete entries from RECENTLY FIXED once they are older than 7 days.
- Dates are YYYY-MM-DD.

Field values:
- Platform:   App | Website | Both | Analytics dashboard   (backend, Modal or database work is noted in the issue text)
- Priority:   Critical | High | Medium | Low
- Status:     Open | In progress | Blocked | Fixed
- Owner:      a name, or Unassigned
- Blocked by: what it waits on (a decision, another issue, a person), or "-"
- Found in:   where it was spotted (an audit, a tester report, a chat)
