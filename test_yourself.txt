EVEBASH - TEST YOURSELF
=======================
Things to check by hand on a real device (website and/or phone app).
Share this file in chats and keep it in the repo so everyone knows what is tested.

HOW TO USE
- Status:   TODO | PASS | FAIL | BLOCKED | RETEST
- Priority: High (launch blocker, test first) | Medium | Low
- When you test, fill:
    Done by           tester name
    Device / browser  e.g. "iPhone 13, iOS 18" or "Chrome 129 on Mac"
    Build / version   app version (e.g. 1.2.4) or website commit / date deployed
    Date tested       YYYY-MM-DD
    Account used      host / guest / logged out + which test account
    Screenshot        file name or link (required for FAIL)
    Fix ref           commit or chat that fixed a FAIL (filled by developer)
    Feedback          what you saw
- If it FAILS: write exactly what happened + screenshot. Developer fills Fix ref and
  sets Status to RETEST; tester re-tests and sets PASS or FAIL.
- New tests go at the bottom with the "Next test number" below, then increase that number by 1.
  Never reuse a number. Pull staging first so two chats don't take the same number.

Next test number: 148

- Test on STAGING (staging.evebash.com / staging app build) unless the test says otherwise.
